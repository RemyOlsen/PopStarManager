## Introduction
This application is built using [React Vite](https://vitejs.dev/) with TypeScript, [Axios](https://axios-http.com/) for API requests, [Tailwind 3.4.17](https://tailwindcss.com/) and some CSS3 for styling on the admin page to show I know how to use it, and [FontAwesome](https://fontawesome.com/) for icons.  
It also includes a .NET backend.

## How to start

### 1. Run the Backend
1. Open and run your first terminal.
2. Navigate to the backend directory:
```sh
cd backend/PopStarManagerApi
```

3. Run the Backend (API)
```sh
dotnet run
```

## 2. Run the Frontend
1. Open and run the second terminal

2. Navigate to the frontend directory:
```sh
 cd frontend
```

3. Install the required dependencies:
```sh
npm install
```

4. Start the development server:
```sh
npm run dev
```
By Default, the frontend will be accessible at: 

http://localhost:5173/
