This documentation will help you understand how to use the API for the Pop Star Manager website

API

Base url: http://localhost:5282/api/

Pop Star

There are several endpoints for the Pop Star API

Pop Star schema

The Pop Star schema is as follows:

Key Type Description
Id int The unique identifier for the pop star. (Auto Generated, can be specified)
Name string The name of the pop star.
Category string The category/genre of music
PricePerHour int The price per hour for the pop star.
Image string The name of the image plus file extension (image.jpg)

Get all Pop Stars

You can get a list of pop star by using the /popstar endpoint.

GET http://localhost:5282/api/popstar [ { "id": 1, "name": "Billie Eilish", "category": "Pop", "pricePerHour": 1000, "image": "billie_eilish.jpg" }, { "id": 2, "name": "Tate McRae", "category": "Pop", "pricePerHour": 900, "image": "tate_mcrae.jpg" }, { "id": 3, "name": "Halsey", "category": "Pop", "pricePerHour": 1000, "image": "halsey.jpg" }, // ...

Get a single Pop Star

You can get a single character by using the /popstar/{id} endpoint.

GET http://localhost:5282/api/popstar/3 { "id": 3, "name": "Halsey", "category": "Pop", "pricePerHour": 1000, "image": "halsey.jpg" }

Filter Pop Stars

You can also filter pop stars in the url by using the different keys in the schema. Available filters:

  • name
  • category
  • price

Name Example

GET http://localhost:5282/api/popstar/name/Billie Eilish [ { "id": 1, "name": "Billie Eilish", "category": "Pop", "pricePerHour": 1000, "image": "billie_eilish.jpg" } ]

Category Example

GET http://localhost:5282/api/popstar/category/Emo [ { "id": 9, "name": "Kellin Quinn", "category": "Emo", "pricePerHour": 400, "image": "kellin_quinn.jpg" }, // ...

Price Example

GET http://localhost:5282/api/popstar/price/1000 [ { "id": 2, "name": "Tate McRae", "category": "Pop", "pricePerHour": 1000, "image": "tate_mcrae.jpg" }, // ...

POST, PUT, DELETE

Important:

You can also add, edit, and delete pop stars.
To perform these actions, you need to use Axios with JavaScript on the frontend or another solution like Swagger or something.

Add a pop star

You can add a popstar by using the /popstar endpoint.

POST http://localhost:5282/api/popstar

This needs to be done with a POST request and the body should contain the new popstar information.

Edit a pop star

You can edit a pop star by using the /popstar/{id} endpoint.

PUT http://localhost:5282/api/popstar/3

This needs to be done with a POST request and the body should contain the updated information.

Delete a pop star

You can delete a pop star by using the /popstar/{id} endpoint.

DELETE http://localhost:5282/api/popstar/3

This needs to be done with a DELETE request from the frontend or other API testing tool.
